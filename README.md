# 可塑性记忆

给 DSH 用的小记忆仓库。分文件夹记事，久了会淡忘。

## 干嘛的

跟 AI 聊久了它记不住你。全塞进上下文又太贵。

所以我把它拆开：主人、约定、续缘、喜好、时间线，一块一个文件夹。想翻哪块翻哪块，剩下的不碰。碰到新话题（工作、家人、宠物）就再开一块，最多 15 块。

记的时候一条不超过 30 字，能三个字说完就别写一句话。

翻开的时候先看一眼索引，就一行，`M主人:3 P约定:1 ...`，看上哪块再打开。

## 装

```bash
node memtree.mjs init      # 建目录
node memtree.mjs idx       # 看索引
node memtree.mjs add M 爱吃辣
node memtree.mjs open M
```

当 DSH 插件装：

```bash
dsh plugin add deepseek-plastic-memory
```

装完设置里会多一页「可塑性记忆」，左边分区右边条目，能直接翻。会话顶栏也多了个 🧠，点开就是同一个面板。

不想装也行，把它当普通 node 脚本用，命令跟上面一样。

## 命令

| 敲这个 | 干这个 |
| --- | --- |
| `idx` | 一行索引，哪个分区多少条 |
| `open <K>` | 翻开某个分区 |
| `add <K> <文本>` | **提交一条待审**（≤30 字，`*` 开头算重要） |
| `add-now <K> <文本>` | 直接写入，跳过审批（自己写用） |
| `pending` | 看待审队列 |
| `approve <id>` | 采纳 |
| `reject <id>` | 驳回 |
| `edit <id> <文本>` | 改待审内容 |
| `done <K> <id>` | 约定办完了，标个 ✓ |
| `rm <K> <id>` | 删掉，进回收站（主人和约定删不了） |
| `mk <名字>` | 开个新分区，最多 15 个 |
| `gc` | 跑一遍遗忘曲线 |
| `init` | 建目录 |

## 子分区

主分区下面还能再开一层，最多两级。比如主人下面挂个「行为」：

```bash
node memtree.mjs mk 行为 M
node memtree.mjs add M>行为 每天一点睡
```

写的时候用 `M>行为` 这种写法。子分区里不能再开子分区。
## 写进去之前先过一眼

模型想记东西不会直接落盘，先扔进待审队列。设置页「可塑性记忆」最上面就是它，每条后面三个按钮：改、驳、采纳。

你自己写的走「自己写一条」，选个分区、填一行，直接生效，不过审批。

`<K>` 是分区代号：`M` 主人、`P` 约定、`C` 续缘、`R` 喜好、`T` 时间线、`X0..X14` 自己开的。

## 东西放哪

默认在 `~/.dsh/plastic-memory/`，`MEMTREE_HOME` 能改。

```
plastic-memory/
  folders.json        # 有哪些分区
  M/notes.md          # 一块一个文件
  P/notes.md
  _trash/2026-10-24.md
```

每行是 `id|时间戳|标记|文本`，纯文本，想手动改也随便。

## 忘得慢一点，也忘得干净一点

人的记忆是这样：刚发生的事清楚，过一阵模糊，再久就只剩个大概，最后忘掉。

这里照着来：

- 7 天内，怎么记的怎么留着
- 7 到 30 天，挑重要的留下，剩下的扫进回收站
- 过了 30 天，整条进回收站

重要的就加个 `*`，能多活一阵。

主人是谁、跟他约过什么，这两块永远不删。约定办完了的（打 ✓），一个月后清掉。

## 更新日志

### v1.2.0

- 加了审批：模型写的记忆先进待审队列，能改、能驳、能采纳
- 设置页加了「自己写一条」，选分区填内容直接写
- 命令行多了 add-now / pending / approve / reject / edit

### v2.0.2

- 写入时不再重复读一遍文件（一次读、一次写）
- 打开分区只读那一个文件，不再扫全部
- 去掉界面里 15 秒一次的轮询，只在操作后刷新
- 记忆库列表只在打开和切换时拉取
- 去掉重复的样式注入

### v2.0.1

- **禁止绕过审批**：`add-now` 现在要内部标记才能用，模型和 shell 调用一律被拒；只有界面里的「自己写一条」能直写

### v2.0.0

- **工作区记忆**：全局库之外，每个 DSH 工作区能各有一份，设置页直接选，不用手打路径
- **两级分区**：主人 › 行为 这种结构，主分区只放子分区
- **折叠浏览**：主分区点开才展开子分区，子分区带父级标记
- **审批**：模型写的记忆先进待审队列，能改、能驳、能采纳；自己写的走「自己写一条」直接生效
- **已存的记忆可改可删**：条目后面有改和删两个按钮
- **主动记**：不用等主人开口，看到新习惯/情绪/约定自己记，但一轮最多一条
- **按问题选分区**：回答前先看索引，一次最多翻两个区，闲聊不翻

### v1.1.0

- 单条从 10 字放宽到 30 字，10 字真不够用
- 变成能装的 DSH 插件，四个工具：`plastic_memory_idx` / `open` / `add` / `gc`
- 设置里多了一页「可塑性记忆」，左边分区右边条目
- 会话顶栏加了个 🧠，点开直接翻
- 修了两个会把 DSH 搞崩的错：`exports` 少写 `./client`、工具少写 `output`

### v1.0.0

- 第一版：分文件夹存、先看索引再翻、遗忘曲线、主人和约定不删
